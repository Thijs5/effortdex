## What changed

**You can record a Pokémon's stats the moment you add it.** The add-Pokémon dialog has a new "Its stats (optional)" section: read the six values off the in-game summary screen right after catching, and each is saved as a stat reading at that level — the same readings the IV calculator uses, so a freshly added Pokémon can already be narrowing down its IVs without a trip through the Level dialog first.

**The Level dialog's stat adjuster gained a `−1` button.** A stat that already has a logged reading showed an Adjust box and a `+1` step; there's now a `−1` on the other side, so a reading that came out lower is one tap instead of typing a negative offset.

No change to existing data — parties, roster, history, and Transfer links are untouched.

## Technical improvements

- **The entire codebase is now TypeScript** (ADR 0026). `lib/`, every component (atoms → organisms → page modules), and the test tree moved from `.js` + JSDoc to `.ts`; `tsc --noEmit` runs in CI alongside the unit and e2e suites. The build (esbuild) and the no-build dev story are unchanged — the shipped `dist/` is still plain ES modules.
- **Every custom element extends a project-owned `BaseElement`** (ADR 0027): one place for `attachShadow` + design-system adoption + the typed `this.$()` ref query, replacing the boilerplate each component repeated. `render()` stays synchronous; `requestRender()` exists but is opt-in.
- **New `<stat-reading-grid>`** (`components/organisms/stat-reading-grid.ts`) — the six-stat "read these off the summary screen" grid, previously inlined in `level.ts`, is now one component shared by the Level dialog and the add-Pokémon dialog. It owns the Gen I Special merge, the shared hint, and the prior-reading Adjust affordance (now with `−1`/`+1`); callers own their wrapper and read `.readings` on their own Save. `level.ts` drops ~180 lines. The IV dialog keeps its own grid — it edits IVs, not readings.
- Added a containerised dev path (`Dockerfile` + `compose.yaml`, `docker compose watch`) and an esbuild-backed dev server (`scripts/dev-server.mjs`) for the TypeScript workflow.
- 352 unit + 120 e2e tests.
