## What changed

**Fixes the v1.12.0 update landing only half-applied.** After the redesign deploy, some visitors saw the new markup but the old stylesheet (or vice versa) until a hard reload. The service worker was precaching the app shell through the browser's HTTP cache on install, so a returning visitor's new worker could copy the *previous* release's still-fresh `styles.css` / `tokens.css` / `index.html` into its brand-new per-release cache. It now fetches each shell file bypassing the HTTP cache, so a release always caches the release's own files.

If you're still seeing a half-updated v1.12.0, one hard reload (or reopening the app) picks up this worker and clears it.

## Technical improvements

- `sw.js` `install` replaces `cache.addAll(SHELL_URLS)` with per-URL `fetch(url, { cache: 'reload' })` + `cache.put` — same all-or-nothing semantics, but the requests skip (and refresh) the browser HTTP cache. ADR 0004 updated.
