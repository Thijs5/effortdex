## Bugfixes

- Fixed grouped history entries collapsing after deleting one nested item. Expanded date batches now stay open and keep showing the remaining entries. Closes #35.
- Fixed the Exp. Share not actually unequipping when toggled off and saved. Turning it off now really clears it instead of leaving it equipped. Closes #39.

## UI / polish

- Gen I/II sprites now get a boxed treatment for the fully-trained glow, while transparent sprites keep the silhouette-style halo.
- Pokérus is now shown directly on sprites: a `PKRS` tag on the Pokémon detail page and a compact status marker on the roster.
- Dialogs now open with focus on the heading instead of the close button or first field, improving keyboard and screen-reader behavior.
- The Level, Nature, Training Guide, and other dialogs now use cleaner spacing and body-contained help notes.
- The Level dialog now treats the “Level” label as plain text, so clicking it no longer changes the value.

## Behavior changes

- Stat-reading entries are now logged on Gen I/II parties too, even though they don’t feed IV math there. This keeps the history complete while preserving legacy mechanics.
- The Level dialog now collapses Gen I’s Sp. Atk / Sp. Def into a single `Special` stat row.

## Technical improvements

- Dialog layout now uses a dedicated body scroll area instead of sticky header/footer hacks, which fixes short-dialog stretching.
- Sprite rendering now detects opaque Gen I/II sprite art and adjusts the visual treatment accordingly.
- Added safer held-item history data so removed items can be named precisely in the log.
- Added coverage for dialog focus, history batch expansion, Exp. Share unequip behavior, Pokérus markers, Gen I special stat handling, and the new sprite opacity logic.
