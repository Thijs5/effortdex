## What changed

**On a phone, a dialog's primary button now stays above the on-screen keyboard.** Focusing a text field in a dialog (Save, Create party, Add…) could push the action row off the bottom of the screen, behind the keyboard. The dialog now tracks the visible area, so its footer sits just above the keyboard and stays tappable.

## Technical improvements

- A modal `<dialog>` is fixed to the layout viewport, which iOS Safari never shrinks for the keyboard (and `interactive-widget=resizes-content` only helps on Chrome). `lib/shell.ts` mirrors `window.visualViewport` onto `--dialog-vv-top` / `--dialog-vv-height` (updated on viewport resize/scroll and a frame after focus moves), and the mobile `.ds-dialog` rule sizes and positions itself from those — the same technique the full-screen species search already uses. Falls back to `100dvh` where `visualViewport` is unavailable.
