## Bugfixes

- The size shown on the Storage page's "Clear cache (… MB)" button now includes the cached PokéAPI data, not just the app files and sprite images. v1.9.3 made that button also clear the PokéAPI data cache, but the figure beside it still only counted the other part — so it read low, often by the larger amount.

## Technical improvements

- `MemoCache#storedBytes(prefixes)` (paired with `clearStored`, sharing a `_storedKeys` helper) returns an approximate byte size of the matching `localStorage` entries; `PokeApiClient#localCacheBytes()` exposes it for the client's own keys.
- `components/pages/settings/cache.js` adds `api.localCacheBytes()` to `estimateCacheSize()` (Cache Storage) for the button label, so the number matches everything the click clears.
- Added coverage for `localCacheBytes` and its scoping.
