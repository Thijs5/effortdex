What's new

1

Active party bar

The current six, pinned above the roster. Tap a slot to mark it fainted/healed. Plain state on the party — not an event.

2

Nav-bar primary swaps

“+ Log a battle” replaces “+ Add a Pokémon” as the pinned action — it's the one run hundreds of times per playthrough.

3

Add a Pokémon, demoted

Moves into the roster toolbar as an icon button next to search/filter, where adding a mon to the box actually belongs.

4

Participant strip

Pre-checked from the last battle minus anyone fainted. Fainted slots are locked, not selectable. EVs apply per selected mon, unchanged math — no new event kind.

Not shown because it isn't UI: fainting, healing and the active six are plain fields on the party (like held item), never written to <ev-history-log>. Only the battle's EV yield itself still goes through the event store, once per selected participant — same call as today's single-mon logBattle().
