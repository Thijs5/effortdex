# 0042 — Game-specific in-game tiers

Status: Accepted. Date: 2026-11-20.

Use Smogon's published in-game efficiency tiers for the exact supported game,
with its native tier notation. Base-stat totals and competitive usage tiers do
not represent main-story efficiency. Bundle factual assignments and source links
for offline use; regenerate with `scripts/update-ingame-tiers.py`.

Preserve version, trade and evolution-branch conditions. Earlier shared stages
can display multiple tiers; sort by the first displayed tier, alphabetically on
ties. Unranked species follow ranked species in either direction. Unsupported
games keep alphabetical/Pokédex browsing without borrowing a remake's ranking.
