# Visual-review sprites

Pinned front sprites from https://github.com/PokeAPI/sprites, under
`sprites/pokemon/{id}.png` (IDs 1, 2, 3, 4, 10, 72, 95, 113, 263, 293, 309, 322, 341, 366).

The screenshot suite uses these local fixtures so participant selection,
relative sprite sizes, and layout can be reviewed without live requests.
Other functional tests retain their minimal network fixtures.
